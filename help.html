这个工具做什么

ppter 把一套演示做成风格统一的图片页。你在这个工作台里说清楚要讲什么，选择文本模型，和模型把页数、受众和风格问清楚，再生成每一页的提示词，然后逐页出图，最后导出 PPTX。 文本和图片都走 APIMart 文档里的接口，使用你自己的 Key。Key 只保存在这台电脑。

同一个页面里的三步

顶部的「写提示词」「逐页生成」「导出 PPTX」是同一页里的三个面板。写提示词使用 OpenAI Responses。 模型可选 gpt-5.2-pro 或 qwen3.8-max。页数、受众、风格或必须保留的事实不清楚时，模型会先追问。 点击「生成详细提示词」后，在右侧核对每一页，再进入逐页生成。已经写好的提示词可以展开「粘贴已有提示词」直接使用。

在本工具中完成
1
写下意图说明主题、受众、页数和必须保留的事实。材料不够时，模型会先追问。
↓
2
生成详细提示词确认分页预览后进入逐页生成。每页之间使用单独一行的 <!-- PAGE -->。
↓
3
逐页生成修改提示词、增删页面、选择风格和清晰度，然后批量生成。
↓
4
导出 PPTX下载整页图片型演示文稿。同页也可以下载 PDF 或按页码整理的图片包。

常见问题

  • 写提示词和生图使用同一把 APIMart Key：在工作台左侧底部「配置 APIMart」中填写；获取 Key / 充值。开源仓库不包含任何人的 Key。
  • 文本模型走 Responses 接口，默认 gpt-5.2-pro。图片模型固定为 GPT Image 2 官方渠道，详见 图片接口文档。
  • 左侧「历史项目」可以删除。删除会移除该项目的页面和对话，并删除它引用的本地图片。
  • 也可以让 Codex、Claude Code 等命令行工具调用 node scripts/codex-cli.js batch ... 直接写入分页提示词，再打开页面人工确认后生成。
